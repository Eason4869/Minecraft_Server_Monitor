# v0.3.2 复审

范围：查询瞬时失败重试、图片通知优先重试、诊断日志、分群授权和取消边界。

- 原问题复现：平台返回 False 后立即发文字且没有图片失败日志；HTTP 503 不重试；图片地址失效后下一轮仍复用缓存。
- 查询：每源最多两次请求，按异常类型判断重试；正常离线和永久错误不重试，备用源只在无有效结果时调用。失败确认仍按监控轮次计数。
- 通知：复用原有每群/每服队列和 5/15 秒退避，前三轮优先图片，最后一轮保留文字回退预算；返回 False 与异常均记录，缓存仅清除失败的图片。
- 分群：各次投递重新读取 UMO 绑定和样式；一言、渲染及最终文字回退前检查授权。测试覆盖退订、关闭通知、缩小通知类型及同群号不同机器人实例。
- 取消：HTTP 退避可取消；渲染锁等待和页面渲染都有预算，异常/取消后释放锁，卸载不恢复缓存或启动后续 HTTP 请求。
- 测试：新增回归先在旧实现上失败，再验证修复；完整 97 项通过。使用真实本地 HTTP 服务及 AstrBot 边界替身。

限制：用户未保留事件现场日志，不能确定 2026-10-22 当时的数据源或平台故障。回归和打包校验不替代部署环境中的 AstrBot / QQ 联调；平台超时后的远端接收状态仍不确定。
